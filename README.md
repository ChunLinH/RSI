# 股票 RSI 实时盯盘助手（第二阶段）

这是一个 Windows 桌面版 RSI 盯盘工具。现已接入腾讯财经的国内 A 股/ETF 实时报价，支持 1、5、15 分钟监控周期；显示 RSI(6)，并以 RSI(6) 产生去重信号和通知。

本阶段不包含自动交易或下单功能。

## 启动

```powershell
py -3 -m pip install -r requirements.txt
py -3 -m pip install -e .
py -3 -m rsi_monitor
```

首次启动时，如果不存在 `config/settings.ini`，程序会自动从不含密钥的
`config/settings.example.ini` 创建默认配置。默认使用上证指数（`000001`），通知默认关闭；需要微信通知时，再编辑生成的 `config/settings.ini`。

Windows 电脑也可以双击项目目录中的 `run_windows.bat`，脚本会检查 Python 版本、安装依赖并启动程序。电脑需要预先安装 Python 3.12 或更高版本，并能访问网络；也可以直接运行 `run_windows.ps1`。

如果不想安装 Python，可以直接下载 [Windows 独立版 RSIWatch.exe](https://github.com/ChunLinH/RSI/raw/v0.2.0/RSIWatch.exe?download=1)，双击即可运行。独立版为单文件程序，不需要额外的 `_internal` 或 `config` 文件夹；首次运行时会自动创建可编辑的配置文件。

## Windows 桌面程序

在 PowerShell 运行：

```powershell
.\build_windows_app.ps1
```

之后双击项目根目录下的 `RSIWatch.exe` 即可启动，不会打开终端窗口。可修改配置在 `config\settings.ini`；如果没有该文件，程序会从 exe 内置的 `settings.example.ini` 创建。独立版为单文件程序，Qt 运行库已内置在 exe 中。

程序默认读取 `config/settings.ini`。国内行情无需 API Key；界面可输入六位 A 股/ETF 代码，也可以输入中文公司名或 ETF 名称搜索添加，并选择 1、5、15 分钟周期。搜索到多个同名或相近标的时会弹出候选列表供选择。添加标的后会加载最近的分钟 K 线，因此可立即显示 RSI；随后每秒以实时价格更新当前 K 线和 RSI。刷新间隔可在 `app.refresh_interval_seconds` 配置。监控清单保存在 Windows 本地数据目录 `%LOCALAPPDATA%\\RSIWatch\\monitor_sessions.json`，重启或更新 EXE 后都会自动恢复；为避免重启时意外发送提醒，恢复后需手动点击“开始全部监控”。点击窗口右上角 × 会将程序隐藏到 Windows 系统托盘，监控继续运行；双击托盘图标可恢复窗口，右键菜单中的“退出程序”才会真正结束监控。

主窗口最小化后会显示透明置顶行情条。单击任意股票行会在行情条旁边打开该标的的分时价格图；空间不足时自动改到另一侧。单击另一行可切换标的，图表右上角 `×` 只关闭图表，双击行情条仍可恢复主窗口。

侧边行情图采用浅色卡片式置顶窗口：展开右侧行情详情时为 960×560，收起详情后为 720×560。顶部可直接点击分时、5 分、15 分、日 K、周 K 和常用技术指标，也支持分时、五日分时、1/5/15/30/60/120 分钟以及日/周/月/年 K 线。图表打开后可直接按 `PgUp`、`PgDn` 切换周期；下方固定显示成交量，并在成交量栏左上角显示鼠标所指（或最新）柱的成交量与成交金额。技术指标可在 RSI、MACD、KDJ 之间切换。

也可以直接在图表区域点击切换：主图右键按照“分时 → 五日分时 → 日 K → 周 K → 月 K”的顺序切换，主图左键按相反顺序返回；年 K 仍可使用下拉框或 PgUp/PgDn 查看。成交量/技术指标区域右键依次切换 RSI、MACD、KDJ，左键反向切换。放大后的 K 线按住主图拖动时只会左右移动，不会误触发周期切换。

交易时段内，每次一秒行情更新都会立即绘制到最右侧尚未完成的分时点或 K 线，并同步更新高、低、收和成交量；新周期开始后自动创建下一根 K 线。后台仍定期重新获取正式 K 线用于校准，接口暂时失败时不会生成虚假数据。

主界面的“显示集合竞价（09:15–09:25）”可控制是否把开盘集合竞价显示在当天分时图左侧。竞价时段固定占横轴左侧约 8%，正常交易时段使用其余区域，不会因数据点较少而铺满整张图。软件在运行并已开始监控时每秒采集一次接口当前可提供的竞价价格和成交量，并保存到本地缓存；关闭显示开关不会删除已采集数据。竞价数据只用于显示和临时 RSI 参考，绝不会触发买卖信号或通知。由于行情接口不能补回已经错过的逐秒快照，如果当天 09:15–09:25 软件没有运行，则无法还原那一段完整竞价过程。

日 K、周 K、月 K 主图叠加 MA5、MA10、MA20、MA60 均线。均线和下方指标始终使用完整历史数据计算，再截取当前可见区间，因此放大后不会出现均线从中间消失或指标数值改变的问题。除分时和五日分时外，其余 K 线周期均可用鼠标滚轮缩放，并以鼠标所在位置为缩放中心；缩放后按住价格主图左右拖动即可浏览更早或更新的 K 线。

鼠标移动到价格主图中的任意 K 线或分时点时，会显示十字线和信息框，包括该点价格、涨跌幅、时间和 RSI(6)。分时涨跌幅统一按“该时刻价格相对当日昨收价”计算；日/周/月等 K 线按相对上一周期收盘价计算。

分时主图以昨收价为中轴，上下使用完全相同的涨跌百分比刻度；即使上午只有上涨数据，下方仍会保留对应的负数区间。右侧以两张卡片显示行情概览和买卖五档，并以红绿横条直观比较各档挂单量。主图右上角的齿轮可随时收起或展开右侧详情，数据随每秒行情刷新；普通公开行情不包含 Level-2 未匹配委托队列。

图表自动关闭开关、集合竞价显示开关、技术指标选择和行情详情栏的展开/收起状态都会保存到 `%LOCALAPPDATA%\\RSIWatch\\ui_preferences.json`，下次启动保持上次状态。默认值也可在 `config/settings.ini` 的 `[chart]` 节点中设置：`show_call_auction = true` 表示默认显示集合竞价，`quote_panel_collapsed = true` 表示默认使用 720×560 的收起模式。

最后一次有效行情和图表数据保存在 `%LOCALAPPDATA%\\RSIWatch\\market_cache`。收盘、周末或网络暂时不可用时会继续显示最近数据，并明确标注“已收盘”或“本地缓存”；这些非实时数据只用于查看，不会产生买卖信号或发送通知。

## 通知配置

默认使用 WxPusher 极简推送。请先在 WxPusher App 的“我的 → 推送渠道”中绑定微信 ClawBot，然后在 `config/settings.ini` 的 `wxpusher_spt` 填入自己的 SPT；`notification_enabled = true` 时，点击界面的“测试通知”可验证通知是否收到。发送结果会显示在“通知状态”和事件区。Server酱仍保留为可选备用渠道，将 `provider` 改回 `serverchan` 即可。

## 国内行情配置

`[market_data]` 默认使用 `provider = tencent_china`，无需 Alpha Vantage API Key。代码会根据前缀自动选择沪市或深市；日志会写入 `[logging]` 中的 `file_path`。
